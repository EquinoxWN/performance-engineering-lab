# Quality check, 2026-11-01

The ten engineering rules, checked against the code on `main`, with the evidence. Run on Windows 11
with JDK 21, Python 3.14 and Node.js 24.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | The only external calls are the harness subprocesses (JMH, pyperf, mitata). `run._run` gives each one a timeout and turns `OSError` and `TimeoutExpired` into `RunError` (exit with a message). Every `except` re-raises as `ResultError`, `SpecError` or `RunError`; none drops an error. `scripts/osv_audit.py` uses a 60 s timeout. |
| 2 | Writes safe to retry | pass | The writes (`.tmp/results/*`, `report.md`) are derived outputs in a git-ignored folder; a rerun rebuilds them from scratch (`make report` regenerates from the stored results). |
| 3 | No race conditions | N/A | Single-threaded harness; each benchmark runs in its own process. |
| 4 | Don't trust the clock | pass | Timing is done by JMH (`System.nanoTime`), pyperf (`perf_counter`) and mitata (`performance.now`); the repo's code does not time anything itself. |
| 5 | Read before changing | pass | `CPUS`, `PY` and `MVNLOCAL` are documented in the Makefile. The child environment only redirects temp folders into `.tmp/` (`test_run.py`). |
| 6 | Never break compatibility | pass | Spec and result formats unchanged. |
| 7 | One source of truth | pass | `spec/experiments.json` drives all three runtimes. Java, Python and JS tests check their seeds, sizes and checksums against it. |
| 8 | Small changes, no secrets, validate input | pass | The secret grep found nothing. Spec files are size-capped and 19 kinds of inconsistency are refused. Result files are parsed strictly (13 malformed inputs refused). Sizes, seeds and bit widths are range-checked in all three languages. |
| 9 | Tests that can actually fail | fixed | No skips and no tautologies. Mutation check: 4 of 18 survived, and each now has a test. |
| 10 | Re-verify | pass | `mvn verify`: 16 passed (Spotless, `-Werror`); pytest 85 passed; `node --test` 9 passed; ruff, mypy `--strict`, tsc clean; pip-audit: none; npm audit: 0; `OSV (Maven): 12 dependencies checked, 0 with known vulnerabilities`; `audit_repo.py`: OK. Benchmarks were not re-run: no measured code changed, and CI runs `bench-smoke`. |
